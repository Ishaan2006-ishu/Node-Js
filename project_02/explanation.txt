🧠 PART 1 — HOW MONGODB ACTUALLY WORKS (MENTAL MODEL)
MongoDB has 3 separate worlds
1️⃣ MongoDB Server (mongod)
2️⃣ MongoDB Shell (mongosh)
3️⃣ Your Node.js Project (Express + Mongoose)


They are NOT the same thing.

1️⃣ MongoDB SERVER (mongod)

This is the engine

It runs in background

It stores data on disk

It listens on port 27017

Think of it like:

Electricity supply ⚡

You start it using:

mongod --dbpath C:\mongodb\data\db


If this is NOT running → nothing works.

2️⃣ MongoDB SHELL (mongosh) — CMD TOOL

This is just a remote control

It lets you talk to MongoDB server

It does NOT store data

Think of it like:

TV remote 📺

You start it using:

mongosh


Now you can:

See databases

See collections

Read / write data

3️⃣ NODE.JS PROJECT (YOUR BACKEND)

Uses Mongoose

Connects to MongoDB server using a URL

Automatically creates DB & collections

Think of it like:

Netflix app 📱
(uses internet but doesn’t own it)

🧠 PART 2 — USING MONGODB IN CMD (NO CONFUSION EVER)
Step 1️⃣ Enter Mongo Shell
mongosh


This means:

“Connect me to MongoDB server running on localhost”

Step 2️⃣ List all databases
show dbs


⚠️ MongoDB only shows databases with data.

Empty DBs are hidden.

Step 3️⃣ Switch to a database
use project_02


Meaning:

“I want to work inside DB named project_02”

If it doesn’t exist:

MongoDB pretends it exists

It is created only when data is inserted

Step 4️⃣ See collections
show collections


Example output:

users

Step 5️⃣ Read data
db.users.find().pretty()


Meaning:

“Show all documents inside users collection”

Step 6️⃣ Insert data manually (optional)
db.users.insertOne({ name: "Manual User" })


Now DB physically exists.

🧠 PART 3 — HOW YOUR PROJECT CONNECTS TO MONGODB

Your Project Folder
      ❌ (NO relation)

Folder name ≠ Database name

You choose to keep them same for clarity — that’s good practice.
